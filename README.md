\# Digital Marketing Campaign Performance Analyzer



\## Project Overview

This Python project analyzes digital marketing campaign data to measure campaign performance.



\## Features

\- Reads campaign data from a CSV file.

\- Calculates Click-Through Rate (CTR).

\- Calculates Conversion Rate.

\- Calculates Cost Per Conversion.

\- Saves the analysis results into a new CSV report.



\## Technologies Used

\- Python

\- CSV

\- PowerShell



\## Input File

`campaign\_data.csv`



\## Output File

`campaign\_report.csv`



\## How to Run

1\. Install Python.

2\. Open the project folder in a terminal.

3\. Run `py main.py`.



\## Note

The project uses sample campaign data for practice and demonstration.
